# CNCF Path

PRI is designed as a cloud-native interoperability contract.

The project should not apply to CNCF until the following are true:

- the v0.1 or later spec is public;
- at least one reference engine implements PRI;
- at least one orchestrator or delivery platform emits or consumes
  PRI-compatible promotions;
- at least one independent embedding example exists;
- governance and contribution process are public.

## CNCF-Friendly Practices

- Apache-2.0 license.
- Public issues and design discussions.
- Public RFC process.
- Documented maintainer path.
- Code of Conduct.
- Compatibility policy before any stable claim.
- Conformance suite before any mature/stable ecosystem claim.

## Positioning

PRI should be presented as an interface, similar in spirit to cloud-native
interfaces such as CRI, CNI, CSI, and CloudEvents. PRI is not a replacement for
delivery, pipeline, fleet, GitOps, VM deployment, or cloud deployment platforms.
